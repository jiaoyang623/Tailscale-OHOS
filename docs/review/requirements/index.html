决策卡

每个决策选一个选项。要改就选「这个决策要改」，并写原因。

决策 1 · 连接什么时候可以停止？

原因：用户报告长时间使用后连接中断。现有逻辑以状态判读决定停止。一次读不到心跳就可能释放保护。

决策 2 · 非用户断连怎么留证？

原因：现有日志只有生命周期事件。无法区分用户停止、扩展崩溃、交接超时与系统停止。

决策 3 · 恢复尝试要设上限吗？

原因：用户要求连接保持到用户停止。固定上限会让后台断连永久不恢复。

决策 4 · 网络离线时怎么等？

原因：离线期间的重试没有用。用户要求网络恢复后自动恢复连接。

决策 5 · 省电在什么条件下降频？

原因：用户报告系统提示耗电较多。用户不在用时，应用不应全速计算。
